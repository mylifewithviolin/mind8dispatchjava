`Dispatcher.setupForDispatch()` は生データを読み込んだ後、情報テーブル配置・対象カーネルメタデータが未検証である旨を出して実行を拒否します。これにより、未解析MCOを命令列として実行することはありません。32バイトという値も計画資料に記載された値を暫定的な短ファイル拒否に使ったもので、Cソース・実データでの再確認はできていません。
